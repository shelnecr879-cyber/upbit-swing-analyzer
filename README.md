# 업비트 4H + 1H 스윙 분석기

WLD / QKC / DOOD / SOPH의 업비트 KRW 시장을 대상으로 4시간봉과 1시간봉을 함께 분석하는 규칙 기반 스윙 분석기입니다.

## 핵심 조건
- 4H: 큰 추세 확인
- 1H: 실제 진입 타이밍 확인
- RSI + MACD + 거래량 + 간단 매물대
- 눌림매수 우선
- 추격매수 방지
- 실제 진입가 기준 손절/목표/R:R 계산
- **1H 상승 추세가 확인된 경우에만 매수 추천**
- **1H 하락 추세가 확인되면 매도 추천/비중축소 신호**

## 실행 파일
- `upbit_swing.py` : 터미널용 분석기
- `streamlit_app.py` : 웹사이트용 분석 화면
- `requirements.txt` : 필요한 Python 패키지

## 웹 배포
GitHub 저장소에 위 3개 파일을 올린 뒤 Streamlit Community Cloud에서 `streamlit_app.py`를 배포합니다.

주의: 이 프로그램은 자동매매가 아닌 기술적 분석 보조 도구입니다. 매수/매도 신호는 규칙 기반 참고용입니다.
